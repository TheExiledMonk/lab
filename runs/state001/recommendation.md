# STATE-001 recommendation

## Recommended next milestone

Proceed to **STATE-002 — Global actuality, slicing, and records closure**, coordinated with the proposed TIME-002 and GEOMETRY-002 gates.

STATE-002 should remain a principle audit until the missing ontology is supplied. It should not derive a new field equation or modify V11. Its first task is to choose or derive exactly one realization rule:

- only one state is actual;
- an ordered segment through the current state is actual; or
- the complete admissible history is actual.

## Required closure gates

1. **Actuality semantics:** define “physically realized,” “past,” “future,” and “coexistence” without using them circularly.
2. **Global-state existence:** state the causal/topological conditions under which a complete global state on a three-dimensional carrier exists.
3. **Slice equivalence:** distinguish gauge-equivalent slicings from physically inequivalent states.
4. **Current-state criterion:** if one state is privileged, define the invariant selector without promoting an arbitrary history label or V11 scale factor to absolute time.
5. **Records criterion:** specify how records and correlations in a state refer to earlier states, without assuming exact reconstruction.
6. **Dynamics firewall:** keep actuality separate from determinism, branching, reversibility, entropy, and information loss.
7. **Relativistic gate:** demonstrate that the chosen ontology yields no observable preferred foliation and preserves the one-metric proper time, causal structure, and coordinate covariance retained by V11.

## Decision rule

If no invariant present-state selector can be supplied, PBUF should remain neutral among the three admissible actuality ontologies. It may still use state histories as a calculational representation, but must not claim that only one universal state exists.

If a single-actual-state principle is adopted, it must be clearly labeled as a new ontological postulate until derived from deeper PBUF microphysics. Determinism, inverse evolution, or the three-dimensional medium premise cannot serve as its derivation.

No cosmological equation, V11 parameter, or existing implementation should change as a result of STATE-001.
