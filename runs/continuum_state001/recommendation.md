# CONTINUUM-STATE-001 recommendation

## Recommended next milestone

Proceed to **ACTUALITY-001 — Physical realization and relativistic slicing of the continuum**.

The milestone should begin from the mechanically derived restriction:

> One complete constitutive state is occupied per material element on each admissible state slice; all phase, branch, memory, mixture, and internal-mode information needed for response belongs to that one enlarged state.

It should then audit, without writing a constitutive or field equation, whether deeper PBUF microphysics supplies the missing cross-history realization rule.

## Required gates

1. Define “mechanically occupied” separately from “ontologically actual.”
2. Decide whether actuality attaches to one state, a growing segment, or a complete history.
3. Define the existence and completeness conditions for a global continuum state.
4. If a current state is privileged, derive an invariant selection rule rather than using a coordinate label, V11 scale factor, or arbitrary foliation.
5. Show how the reference configuration and any causal memory enter the current state without being misclassified as co-occupied universal states.
6. Prove that mechanically equivalent slicings yield the same deformation invariants, stored energy, response, and effective observables.
7. Preserve V11's operational Lorentz invariance, one-metric proper time, standard dynamics, and cosmological equations.
8. Keep actuality independent of determinism, reversibility, entropy production, and reconstructibility unless those properties are separately derived.

## Development decision

PBUF may now state that its elastic-continuum ontology requires **mechanical state uniqueness at an admissible state position**. It should not yet state that only one universal state exists across history.

Current-state realism may be used as the preferred working interpretation because it aligns directly with constitutive evaluation and evolution language. It must remain labeled an interpretation until ACTUALITY-001 supplies the missing physical rule.

No V11 equation, constitutive law, physical parameter, or implementation should change from this milestone.
